# Security Policy

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a vulnerability

Please do **not** open a public issue for a security problem. Use
GitHub's private vulnerability reporting for this repository
(Security tab → Report a vulnerability), or contact the maintainer
through a private channel.

What to include: the affected module, a minimal reproduction, and the
impact you believe it has. The maintainer will acknowledge the report,
assess it, and prepare a fix before any public disclosure.

## Scope notes

VoiceTrainer VN processes audio files and transcripts supplied by the
user. It never uploads data anywhere: the toolkit is fully offline.
When handling other people's voices, remember that voice data is
personal data — collect it only with consent, and never commit real
recordings or transcripts to this repository.
